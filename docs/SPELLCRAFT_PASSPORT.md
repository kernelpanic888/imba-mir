# Паспорт конструирования магии IMBA

**ID:** `IMBA-SPELLCRAFT-v1`  
**Статус:** `IMPLEMENTED VERTICAL SLICE / PLAYTEST OPEN`  
**Обещание:** игрок собирает заклинание сам, понимает причину распада и видит
магический эффект, который честно соответствует выбранной формуле.

## Заклинание и магия

Заклинание — человечески читаемая формула из рун. Магия — фактическое изменение
Мира после допуска формулы. Интерфейс не имеет права показывать успешный контакт,
если Lean вернул `HOLD`.

## Изумрудный проводник

Когда формула собрана, Проводник обязан:

1. назвать ослабленные каналы `F / C / R` и точный дефицит;
2. проверить все варианты одной замены в текущем наборе рун;
3. предложить только замену, которая действительно уменьшает дефицит или
   замыкает обязательную синергию;
4. показать прогноз каналов после замены;
5. явно подписать совет как `ПРОЕКЦИЯ · НЕ ВЕРДИКТ`;
6. оставить применение замены отдельным действием игрока.

Если одной заменой формулу исправить нельзя, Проводник говорит это прямо и не
собирает заклинание автоматически. Финальный `APPEND`, `APPEND_WITH_COST` или
`HOLD` возвращает только Lean.

## Критерии приёмки

- причина распада понятна без чтения журнала;
- совет изменяет ровно одну выбранную руну;
- прогнозируемые `F/C/R` совпадают с формулой после применения;
- кнопка совета не отправляет заклинание автоматически;
- при устойчивой формуле Проводник не обещает результат до проверки Lean;
- весь конструктор помещается на одном экране Steam Deck-профиля.

## Открытая граница

Автоматические расчёты и production-сборка проверяют контракт. Отдельный
плейтест ещё должен подтвердить, что игрок действительно учится распознавать
синергии, а подсказка не превращается в единственно очевидный оптимальный ход.
