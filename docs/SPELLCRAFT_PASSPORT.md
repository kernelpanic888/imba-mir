# Паспорт конструирования магии IMBA

**ID:** `IMBA-SPELLCRAFT-v1`  
**Статус:** `IMPLEMENTED VERTICAL SLICE / PLAYTEST OPEN`  
**Обещание:** игрок собирает заклинание сам, понимает причину распада и видит
магический эффект, который честно соответствует выбранной формуле.

## Заклинание и магия

Заклинание — человечески читаемая формула из рун. Магия — фактическое изменение
Мира после допуска формулы. Интерфейс не имеет права показывать успешный контакт,
если Lean вернул `HOLD`.

## Изумрудный проводник

Когда формула собрана, Проводник обязан:

1. назвать ослабленные каналы `F / C / R` и точный дефицит;
2. передать собранную формулу в Lean и проверить конечное пространство `4⁴`;
3. получить от Lean минимальный допустимый маршрут: сначала минимум замен,
   затем минимум объявленной цены напряжения;
4. показать весь маршрут по слотам, итоговые `F/C/R`, синергию и вердикт;
5. явно подписать совет как `ПРОЕКЦИЯ · НЕ ВЕРДИКТ`;
6. оставить каждую замену отдельным действием игрока;
7. потребовать повторного подтверждения собранной цели в Lean.

Проводник не ограничен одной заменой и не выдаёт локальную эвристику за закон.
Фронтенд только отображает маршрут, рассчитанный ядром. Выбор руны меняет
кандидат формулы, но не состояние Мира. Финальный `APPEND`,
`APPEND_WITH_COST` или `HOLD` возвращает только Lean; только после этого могут
измениться ранг, сертификат, дорога и напряжение.

## Критерии приёмки

- причина распада понятна без чтения журнала;
- маршрут имеет доказанный минимум замен и явно объявленную цену;
- каждый шаг изменяет ровно одну выбранную руну и виден на Срезе реальности;
- прогнозируемые `F/C/R` совпадают с целевой формулой;
- кнопка шага не отправляет заклинание автоматически;
- при устойчивой формуле Проводник не обещает результат до проверки Lean;
- весь конструктор помещается на одном экране Steam Deck-профиля.

## Открытая граница

Автоматические расчёты и production-сборка проверяют контракт. Отдельный
плейтест ещё должен подтвердить, что игрок действительно учится распознавать
синергии, а подсказка не превращается в единственно очевидный оптимальный ход.
