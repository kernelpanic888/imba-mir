# Модульные паспорта IMBA

**ID:** `IMBA-PASSPORT-INDEX-v1`  
**Статус:** `ACTIVE / MODULAR SOURCE OF TRUTH`  
**Назначение:** карта независимых проектных контрактов IMBA.

Прежний [`GOOD_GAME_PASSPORT.md`](./GOOD_GAME_PASSPORT.md) остаётся архивной
сводкой замысла, но больше не является местом, куда добавляются требования ко
всему сразу. Новое правило проекта:

> Один модуль — одно обещание игроку, один набор правил, один пакет проверок и
> отдельный статус готовности.

Модули не усредняются. Красивый визуал не закрывает правила боя; глубокая
прогрессия не закрывает нечитаемое действие; работающий код не закрывает
непроверенное переживание.

## Статусы модуля

1. `RESEARCHED` — источники и границы собраны.
2. `SPECIFIED` — написан нормативный паспорт и критерии приёмки.
3. `IMPLEMENTED` — вертикальный срез реализован без фиктивных состояний.
4. `VERIFIED` — автоматические проверки и визуальный аудит прошли.
5. `PLAYTESTED` — целевые игроки подтвердили обещанный опыт.
6. `CLOSED` — нет блокирующих расхождений между исследованием, паспортом,
   кодом и наблюдаемым опытом.

Слово `CLOSED` запрещено использовать только потому, что документ написан или
сборка проходит.

## Порядок работы

Текущий активный модуль — **Баланс и калибровка**. Визуальный язык остаётся
обязательным измерительным слоем: числовой патч не принимается, если срез
реальности перестаёт честно показывать причину. Первый пакет калибровки закрывает
мёртвую синергию `REMEMBRANCE`, затем ограничивает неограниченное линейное
высвобождение истории, не отменяя рост напряжения.
